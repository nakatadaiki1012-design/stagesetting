# 🎼 ステージ配置図メーカー

吹奏楽・オーケストラ・ビッグバンドなどの**ステージ配置図**を、かんたんに作れるWebアプリです。
インストール不要。パソコン・スマホ・iPad のブラウザで動きます。

## できること

| こまったこと | このアプリでは |
|---|---|
| 細かい作業が面倒 | **ひな形**（吹奏楽・小編成・オケ通常/対向・弦楽・ビッグバンド）から一発で作成。<br>「8,10,12,14」と人数を入れるだけで**扇形の席をまとめて作成**。<br>「Fl×4, Ob×2, Cl1×3」で**パート名を一括割り当て**、名前も一覧を貼るだけで一括入力。 |
| きれいな形に整理したい | **✨きれいに整える**ボタンで、列を自動で見つけて**扇形（または横一列）・等間隔・指揮者の方を向く**ようにそろえます。パートの切れ目や通路のすき間は残します。<br>左右そろえ・等間隔・重なり解消・左右反転もあります。 |
| 既存のステージ図面を自動でトレースしたい | 配置図の**写真・スクショ・画像**を読み込むと、椅子（丸や四角）を自動で見つけて席にします。縮尺と指揮者の位置も自動で推定。オプションで文字（パート名）の読み取りもできます（ネット接続が必要）。 |

**かんたん編成**：ホール（神奈川県・東京都の34ホールのステージ寸法入り）を選び、パートの人数を▲▼で変えると、すぐに自動で並べ直します。

**編成の種類**：吹奏楽・オーケストラ・弦楽・ブラスバンド・ビッグバンド・合唱。ひな形にも「ブラスバンド」「ビッグバンド」「合唱（混声4部）」「女声合唱」があります。
- **ブラスバンド**（ブリティッシュ・スタイル）：列は **台形のコの字**（指揮者の左の腕 → 奥の辺 → 右の腕。腕は客席の方へ少しひらく）。前の列は下手の腕にソロ・コルネット、奥の辺にフリューゲル → テナーホルン → バリトン、上手の腕にユーフォニアム。後ろの列は下手の腕にソプラノ・レピアノ・2nd・3rd コルネット、奥にBb・Eb ベース、上手の腕にバストロンボーン → トロンボーン。打楽器は後ろ。これまでの扇形も「並び方」の「扇形」で選べます。
- **ビッグバンド**：サックスが前（下手から T1・A2・A1・T2・Bari。リードのA1が真ん中、ソロのT1がリズム隊の近く）、トロンボーンが1段目（Tb2・Tb1・Tb3・B.Tb）、トランペットが2段目（Tp2・Tp1・Tp3・Tp4）。各列のリードを縦にそろえます。リズム隊は下手にまとめ、ドラムはトロンボーンの台の下手どなり（奏者はセットの後ろに座り、客席と管の方を向く）、ベースはドラマーの右手側の少し前、ギターはサックスの列の下手どなり、ピアノはいちばん前の下手。指揮台は置きません。
- **ドラムセットの絵**：奏者はセットの後ろに座ります。奏者の側にスネア（ひざのあいだ）とハイハット（左手側）とフロアタム（右手側）、客席の側にバスドラム（ヘッドは前後）とシンバル。3D も同じ並びです。
- **合唱**：立って楽譜のファイルを持つ「歌う人」の形（図と3D）。並び方は「S・A・T・B を下手から」「女声が前・男声が後ろ」「S・T・B・A」。前の列は床、うしろの列は合唱用のひな壇に1段1列で、うしろの列は半人分ずらして前の人の頭のあいだから顔が見えるようにします。ピアノは下手（ピアニストは合唱と指揮者の方を向く）。

**打楽器の楽器を1つずつ**：「打楽器」の箱の「楽器（台数）」で、ティンパニ・大太鼓・小太鼓・シンバル・タムタム・グロッケン・シロフォン・ヴィブラフォン・マリンバ・チャイム・小物台・ドラムセットを増やしたり減らしたりできます。決めていないときは打楽器の人数から自動で、「人数に合わせて自動に戻す」で元に戻せます。楽器が奏者より多くなると、打楽器の人数も増やします。

**オーケストラの打楽器**（奏者の目線）：ティンパニは最上段の真ん中（トランペット・低音の近く）。ほかは奥から 大太鼓 → 小太鼓 → シンバル → 小物 → 鍵盤 の順に、弦の扇形の外側を下手の前の方へまわりこむように並べ、指揮者の方を向けます（鍵盤は客席へ少しひらく）。最上段の下手の横には、ティンパニを運び上げる通路を残します。

**反射板の形**：ホールを選ぶと、音響反射板を置いたときの舞台（前の幅・奥の幅・奥行）になります。公開値が見つからないホールは推定値（△・要確認）です。ホールを選ぶと、選ぶ欄のすぐ下に「寸法は目安です。本番前に必ずホールの舞台図面で確認してください」と出ます（△のホールは、より目立つ色と枠で）。

**ひな壇**：平台の置き方（3×6尺の横置き・縦置き、4×6尺、6×6尺など）を図で選び、箱馬の高さ（7寸・1尺4寸・2尺1寸・2尺8寸）で段を作り、必要な部材の数を表示します。ひな壇の上はまっすぐ並びます。ホルンのボックス型、打楽器の自動整列にも対応。

**舞台の大きさをドラッグで**：舞台の角・前の縁の丸いつまみをドラッグすると、前の幅・奥の幅・奥行が変わり、自動配置ならすぐ並べ直します。

**吹奏楽の並び方・ひな形**：標準（前列Fl・Cl／ひな壇1段目Hr・2段目Tp・Tb）、Cl下手・Sax上手、昔ながら、ドイツ式から選べます。ひな形（標準・コンクールA 55人・小編成・オーケストラなど）も同じ仕組みで作るので、ひな壇は平台の実寸（3×6尺・4×6尺・6×6尺）で全段同じ幅になります。

**✍️ 文章で指示する**：「フルート6人、打楽器は下手、ひな壇2段、ミューザで」のような文章から、人数・並び方・打楽器の場所・ひな壇・ホールを決めて並べ直します（「コンクールA」「小編成」「2管編成」などのひな形の名前や、「55人くらい」「合計40人」のような全体の人数もわかります）。読み取れなかったときは、書き方の例を出します。画面にはAIのことは出しませんが、claude.ai で開いたときは、これまでどおり Claude が文章を読んで考えます。

**弧・円形の舞台**：前のふちが弧の舞台（サントリーホール・ミューザ川崎・みなとみらいなど）や円形・楕円形の舞台。弧のふくらみはつまみで調整。

**譜面台の3本脚**：開いたときの直径 約54cm（オーケストラ用譜面台の台座 約21インチ）を図と3Dで表示（設定で切替）。

**弦楽器は2人で1本の譜面台**：ヴァイオリン・ヴィオラ・チェロ・コントラバスは、となりの同じパートの人と2人で1本の譜面台（プルト）にします。かんたん編成・ひな形では、組の2人を少し近く、組と組のあいだを少し広く並べます。古い保存データや手で置いた配置でも、となりどうしを自動で組にします。奏者を選ぶと「この2人で1本にする」「1人1本にする」「自動にもどす」で変えられます。「編成表」に譜面台の本数が出ます。譜面灯も1本に1つです。

**弧（円形）のひな壇**：かんたん編成の「ひな壇の形」で **弧（指揮者を中心に）** をえらぶと、ひな壇を指揮者を中心にした弧にし、段の上の人も弧に沿って指揮者の方を向きます（段がとても広いときは、急な弧にならないよう中心を少し客席側にします）。平台は1枚ずつ扇に並べて描き、組み図・部材の表・3Dにも出ます。舞台からはみ出す・床の人とぶつかる段は、まっすぐのままにします。手で置いたひな壇も、選んで「形」を「弧（円形）」にしたり、「🎯 指揮者を弧の中心にする」で合わせたりできます。

**3Dのパート名**：パート名の札は、遠くからでも読めるよう画面の上でいつも同じ大きさにし、パートの色のふちを付けました。3Dの下の「文字 小・中・大」で大きさを変えられます。2人で1本の譜面台の組は、札を1枚にしています。

**✨きれいに整える（ひな壇・舞台の大きさに合わせる）**：押すと次のように整えます。
- ひな壇のふちから少しはみ出して「落ちかけている」人は段の上に乗せ、床の列から段にかかっている人は段から降ろします。
- 段の上の人は段ごとに、段の上にきちんと並べます（まっすぐの段は列に、弧の段は弧に沿って指揮者の方を向く）。人数が多い段は間隔を詰め、段からはみ出させません。
- 何も選んでいないときは、舞台からはみ出す・舞台奥の通路にかかるひな壇を、上の人・楽器ごと舞台の中へ動かし、舞台の外の指揮台も舞台の中へ入れます。
- 床の列が舞台に入らないときは、指揮者の方へ少しずつ詰めます。それでも入らない・舞台より広いひな壇があるときは、お知らせで教えます。
- 花道・オーケストラピットのふたの上にいる人（ソリストなど）は、そのままにします。花道・ピットのふたは3Dでも舞台と同じ高さの床として出ます。

**ひな壇の後ろの打楽器**：ひな壇があるときは、舞台奥の打楽器も最上段より1段高い「打楽器の段」に乗せます。打楽器の段は最上段にくっつけ、反射板とのあいだには通路を残します。

**舞台奥の通路**：反射板（舞台の奥）と、ひな壇・楽器・奏者のあいだに通路を空けます（はじめは60cm。「かんたん編成」の「安全・ホールの設備」の「舞台奥の通路」で変えられます）。かんたん編成・ひな形はこの幅を空けて並べ、これより狭い所があると「⚠ 確認」に出ます。

**ひな壇の組み図**：ひな壇は平台1枚ずつの線と番号（「段の番号-前の列の下手から数えた番号」、例：1-3）、箱馬（足）の位置を描きます。番号は「編成表」の部材の表と同じです。「📤 書き出す」の画面の「中身」で **ひな壇の組み図** をえらぶと、段・平台・足・上がり段だけの図と部材の表を1枚にして出せます（PNG・PDF・SVG・印刷）。

**花道（張り出し）**：「部品」の **花道（張り出し）** は、舞台と同じ高さの板張りの床です。客席の方や舞台の横へ出して置け、長さ・幅・向きは自由に変えられます。上にソリストなどを置けば、舞台の外でも「✨ きれいに整える」「🔧 自動で直す」で動かしません。3D でも舞台と同じ高さの床として描き、その下の客席のいすは置きません（ホールに常設の花道は「ホールの設備」に入れます）。

**上がり段・搬入経路の確認**：「部品」の **上がり段** を段の横か前にくっつけて置けます。高さ40cm以上の段に人や楽器が乗っているのに、上がり段も1段低い段とのつながりもないときは「⚠ 確認」に出ます。マリンバ・ティンパニ・グランドピアノ・ヴィブラフォン・シロフォン・チャイム・タムタムが段の上にあるのに、段の横・前・後ろに幅1.2mほど空いた床がないときも「⚠ 確認」に出ます。

**ホールの設備**：「かんたん編成」の「安全・ホールの設備」→「ホールの設備」に、反射板の位置・プロセニアム・緞帳線・迫り・オーケストラピットのふた・花道・**上手／下手の出入り口（扉）** を、分かるものだけ入れられます（空欄のものは描きません）。出入り口は「＋ 出入り口を追加」で、どちら側（下手・上手）・舞台の奥のふちから扉の真ん中まで・扉の幅を入れます。図に緑の「出入口」と空けておく所（扉の前 1.2m、点線）を描き、3D では横の壁に扉を描きます。扉の前に人や物があると「⚠ 確認」に出て、かんたん編成は扉の前を空けて並べます。図に描き、奏者や物が重なると（例：緞帳線の上に椅子がある）「⚠ 確認」に出ます。ホール一覧のデータにも同じ形で入れられますが、確かめた値がないので、今はどのホールにも入っていません。

**譜面灯・電源**：奏者を選んで「譜面灯をつける」、または「編成表」の「💡 全員に譜面灯」「全員はずす」で、譜面台に譜面灯（光の線つきの丸。白黒でも分かる形）を描きます。「部品」の「電気・音響」に **コンセント（2口）** と **延長コード（4口タップ）** があります。「編成表」に譜面灯の数・必要な差し込み口の数（2口のコンセントなら何か所分か）、置いたコンセントとタップで足りるかが出ます。図面の編成欄にも「譜面灯 ×○」「電源 ○口」が入ります。

**録音・音響**：「部品」の「電気・音響」に **録音用マイク（高いスタンド）** と **モニタースピーカー** があります。マイク・モニターを選んで「← 下手の袖へ」「上手の袖へ →」を押すと、舞台袖までの **ケーブルの通り道** を線で描きます（客席側の物は舞台の前のふちに沿って、奥の物は舞台奥の通路を通します）。線を選ぶと出る白い丸（折れ点）をドラッグして道を直せ、「＋ 折れ点を足す」で曲がる所を増やせます。画像・PDF・印刷の画面で **「音響の機材（マイク・モニター・ケーブル）を入れる」** のチェックを外すと、音響の機材を除いた図面にできます。

**前の版とくらべる**：「💾 保存/開く」で、保存した配置図の「くらべる」、前の版の「第○版とくらべる」、または「🔍 ファイルとくらべる」を押すと、いまの配置図との違いを図に出します。**増えた物＝緑の○と＋、減った物＝うすい元の形と赤い点線の□と−、動いた物＝前の位置からのオレンジの矢印**。色だけでなく形でも分かるので、白黒で印刷しても読めます。「名前を付けて保存」で版を上げると、前の版も自動でとっておきます（10版まで）。くらべている間は、下の「変更の内容に入れる」で「第2版：Tp +1、Cl1 −1、3か所移動」のような **変更メモ** を作れます（「📤 書き出す」の画面の「図面の情報欄」の「変更の内容」でも入力・修正できます）。変更メモは図面の情報欄の「変更」の行に出ます。画像・印刷の画面で「違いの印を入れる」をえらぶと、印と見方の説明も図面に入ります。

**指揮台の前**：かんたん編成・ひな形は、指揮台の前から舞台の縁まで1m以上空けて並べます（幅は「かんたん編成」の「安全・ホールの設備」の「指揮台の前から舞台の縁まで」で変えられます）。空いていないときは「⚠ 確認」に出ます。

**重なりの確認**：奏者の椅子・譜面台（2人で1本なら1本）・楽器が互いに重なっているとき、ひな壇の縁に椅子や譜面台がかかっているとき（段の上の人の譜面台が段から落ちているときも）、「⚠ 確認」に出ます。かんたん編成・ひな形は、こうした重なりが起きない並べ方を選びます（扇形を左右に広げて舞台の左右も使う・ひな壇の前の列は譜面台まで段に乗る位置にする・オーケストラの弦は同心円の列ごとにパートの順に座る、など）。

**オーケストラのティンパニ**：「打楽器の場所」の **ティンパニは最上段の中央＋ほかは下手** で、ティンパニをいちばん高い段（金管の段）の真ん中・奥に置きます（その段は3×6尺を横2列）。オーケストラのひな形はこの置き方が標準です。

**⚠ 確認（警告の一覧）**：通路・指揮台の前・重なり・上がり段・搬入経路・ホールの設備の警告は、舞台図の左上の「⚠ 確認 ○件」にまとめて出ます。押すと一覧が開き、1つ押すとその場所へ移動して、赤い点線の枠で示します（枠と番号は画面だけで、画像・印刷には入りません）。一覧のいちばん上の **「🔧 自動で直す」** を押すと、指揮台の前（床の人ごと奥へ）・舞台奥の通路（前へ）・ひな壇の縁（段に乗せる／降ろす）・重なり（少しずつ離す）・上がり段（段の横に付ける）を、形をくずさずに直します。指揮台の前は「全体を奥へ」「床の人だけ奥へ」「指揮台だけ奥へ」を試して ⚠ がいちばん少ないものを使います（扇形はくずしません）。それでも残った所は、赤い枠にかかっている物を、楽器と奏者のまとまりごと（段なら上の人・物ごと）8方向に少しずつ（12cm〜1m）動かしてみて、⚠ が減る場所を探します（重なり・出入り口・緞帳線・迫り・ピットなど）。段が出入り口の前にかかるときは、その側の平台を1列ずつ外して段をせまくします。1つずつ試して、⚠ が増える手直しは残しません。直したあとで ⚠ が増えるときは元のままにし、直せない所（重い楽器の搬入経路など）は一覧に残して案内します。かんたん編成で作った図なら「設定で並べ直す」も選べます。

**打楽器を下手に**（吹奏楽・奏者の目線の並べ方）：「打楽器の場所」を「下手側」にすると、次のように並べます。
- **ティンパニ**：ひな壇の1段目の横（下手側）の床に、正面（客席）向き。低い太鼓が奏者の左（日本でふつうのインターナショナル式）。
- **鍵盤（前の列）**：床の扇形のすぐ外側に、前（客席寄り）から グロッケン → シロフォン → ヴィブラフォン → マリンバ → チャイム（背の高いチャイムは端）。指揮者を見ながら、共鳴管の音が客席へ届くよう、客席の方へ少しひらきます。
- **太鼓類（すぐ後ろの列）**：鍵盤の後ろに、バンドの真ん中に近い方（奥）から 大太鼓 → シンバル → 小太鼓 → 小物台（大太鼓とシンバルは同じリズムが多いので、となりに）。
- 入りきらないときは、これまでどおり舞台奥の角にまとめます。

**楽器と奏者はくっついて動く**：打楽器の奏者は、演奏する楽器のすぐ後ろ（演奏する位置）にいます。楽器か奏者をドラッグする・向きを変えると、いっしょに動きます（ティンパニは4台と奏者がひと組）。Alt を押しながら動かすと、それだけ動きます。右のパネルの「楽器と奏者をいっしょに動かす」を外すと別々に、手で置いた楽器と奏者は、両方を選んで「🔗 楽器と奏者をくっつける」で、奏者が演奏する位置へ動いてくっつきます。

**並べ方の点数**：自動配置は、重なり・段の縁にかかる人に加えて、重い楽器を段に運び上げる通路があるかも見て、いちばんよい並べ方をえらびます。

**ひな壇のマグネット**：ひな壇・平台・上がり段をドラッグすると、近くの段の左右・前後のふちにぴったりくっつき、端や真ん中にもそろいます（ピンクのガイド線）。Alt を押しながら動かすと、くっつきません。

**奏者の間隔**：右の「整える」の「↔ 間隔を広げる」「→← 間隔をつめる」で、床の人は指揮者からの距離ごと、段の上の人は段の中で、間隔を少しずつ変えられます（舞台・ひな壇からはみ出す・重なる手前で止まります）。かんたん編成の「並び方」の「となりとの間隔（つめる・ふつう・ゆったり）」でも決められます。舞台がせまくて間隔を詰めて並べたときは、そのことを案内します。

**舞台図を重ねる**：ホールの舞台図（PDF・画像）を読み込んで配置図に重ねられます。白い余白は自動で切り取り、図の舞台の前の角（または奥の角）を2か所タップすると大きさ・回転・位置がぴったり合います。PDFは縮尺（1/100など）から実寸に、画像は「2点の長さ」で縮尺を合わせられます。大きな図がはみ出しても、切り取り・全体表示・画像保存時に紙を広げる、で対応。重ねた図からそのまま椅子の自動読み取りもできます（PDFの読み込みはネット接続が必要）。

**舞台図面として配れる**：画像（PNG・SVG）・PDF・印刷で、用紙（A4・A3、縦・横）と縮尺（1/50・1/100・1/200・用紙に合わせる）をえらべます。縮尺をえらぶと紙の上の長さが実際の寸法どおりになり（1/100 なら 1m が 1cm）、スケールバーも入ります。舞台が用紙に入らないときは警告し、入る縮尺を案内します。図には上手・下手・客席・センター（中心線）が必ず入り、右下の情報欄に公演名・会場・日付・第何版・作った人・縮尺・メモが入ります（画像・印刷の画面の「図面の情報欄」で入力。「名前を付けて保存」のときに版を1つ上げるか聞きます）。PDF はアプリの中で作るので、ネットにつながっていなくても作れます（うまくいかないときは印刷画面の「PDFに保存」でも作れます）。

**白黒◯×**：色を使わず、パート名・椅子○・譜面台×・ひな壇の段・寸法を黒い線と文字で描きます。コピーやFAXでも読めます（前の「コンクール用（椅子○・譜面台×）」と「図面用（白黒・線だけ）」を1つにまとめました。前に保存した図も、この表し方で開きます）。

**🎺 コンクール提出用**：「📤 書き出す」のいちばん上の **「🎺 コンクール提出用（白黒◯×）」** を押し、「PDFを作る」（または「PNG画像を作る」）を押すだけで、A4・紙いっぱいの白黒◯×の図ができます（ひな形を選んでから3回）。
- 入れるのは **団体名（学校名）** と **メモ（部門・出演順など自由に）** だけ。どちらも空でも作れます。
- 図に出すのは、舞台の形・ひな壇の段（高さは小さな字）・椅子◯・譜面台×・パート名・打楽器などの楽器・指揮台・客席の向き・団体名とメモ・編成表（選んだときだけ）です。寸法の線・センター線・平台の継ぎ目・縮尺のものさし・情報欄は出しません。
- ×はその人の◯の前（指揮者側）に少し離して描き、パート名は◯・×・段のふちの線と重ならない所に置きます（入らないときは◯の中）。
- 提出の書式は大会や支部の要項で違うことがあるので、用紙の向き（横・縦）と編成表を入れるかは選べます。要項を確かめてください。

**すっきりした表示**：はじめて使うときは、パート名・舞台の大きさの寸法・センターの線・上手／下手／客席だけを出し、方眼・譜面台の3本脚・ひな壇の平台の番号と足の印は出しません（「設定」の「表示」で出せます。ひな壇の組み図には、平台の番号と足の印がいつも入ります）。前から保存してある配置図・共有リンクは、そのときの表示のままです。「ステージの大きさ・形」と「安全・ホールの設備」は「かんたん編成」の下の開け閉めできる箱に、タイトルと図面の情報欄（最初は閉じてあります）は「📤 書き出す」の画像・PDF・印刷の画面にあり、「設定」タブには「表示」だけがあります。

**ボタンの置き場所**：
- 上の **「📤 書き出す」** を押すと、**画像（PNG・SVG）・PDF・印刷** からえらべます（前の「🖼 画像」「🖨 印刷」を1つにまとめました）。いちばん上は「🎺 コンクール提出用」です。作成ボタンは画面の下にいつも見えています。
- 左のタブは **かんたん編成・ひな形・部品** の3つです。**一括作成**（配置のくふう・扇形をまとめて作る）と **トレース**（舞台図を重ねる・画像の読み取り）は **「もっと…」** の中にあります。
- 「かんたん編成」で最初に見えるのは **ホール・編成の種類（吹奏楽・オーケストラ・弦楽）・パートの人数** だけです。**文章で指示する・並び方・打楽器・ひな壇・ステージの大きさ・形・安全・ホールの設備** は、その下の開け閉めできる箱の中にあり、最初は閉じています。閉じたままでも、見出しに今の設定（例：「ひな壇 2段・3×6横・2列」）が出ます。平台の置き方は、よく使う **3×6横・2列／3×6縦／4×6横** の3つを見せ、ほかは「ほかの置き方」の中にあります。
- 人数が0人のパート（Es.Cl・ハープ・ピアノなど）は隠れています。**「＋パートを追加」** で出せます。
- スマホでは、上のボタンのアイコンの下に小さな文字（戻す・進む・保存・書き出す・共有・使い方）が出ます。3Dのボタンは、スマホでは左のパネルの **「もっと…」→「🧊 3Dで見る」** にあります。
- スマホで開いたとき・ひな形を選んだときは、舞台を画面の幅いっぱいに出します。寸法は「前の幅」と「奥行」だけにし、下手・上手は舞台の前の角の下に出します（パソコンは今までどおり）。
- 右の「選択中」タブは、何も選んでいないときは「整える」のボタンだけです。**複製・削除・同じパートを選ぶ** は1つ以上、**位置合わせ（⇤⇹⇥・等間隔）** は2つ以上選んだときに出ます。

**舞台図らしい表示**：方眼を 50cm／1m／1.82m（1間＝平台の6尺、中心線と舞台の前のふちから）で表示。奏者を「人の形」「○」「白黒◯×（椅子○・譜面台×）」から選べます。

**選び方と整え方**：四角・投げ縄（自由な形）で囲んで選択（ひな壇は選ばれない）。「弧のカーブ」スライダーで扇形をゆるい弧〜まっすぐに。

**寸法の自動表示**：舞台の前の幅・奥の幅・奥行を常に表示。平台などを選ぶ・動かすと、指揮台・舞台際・舞台奥・下手／上手までの距離がその場で出ます。

**低音を上手の外側の弧に・ホルンのボックス**（左のタブの「もっと…」→「一括作成」）：B.Cl・ユーフォニアム・チューバ・弦バスを上手側の外側の弧にまとめる配置（弦バスがいちばん外）を選べます。

**3Dビュー**（天井なしで真上からも見える。服をパートの色にすると濃い色で区別。グランドピアノは実物の形）：客席から・指揮者から・奏者の席に座った目線で、立体で確認できます。演奏者の服・関節・影、ホールの壁・バルコニー・客席まで再現（Three.js を使用。ネット接続が必要）。

**図が消えないように**：自動保存・「名前を付けて保存」の保存先は、このブラウザの中だけです（ブラウザのデータを消したり機種を変えたりすると消えます）。「💾 保存/開く」のいちばん上にそのことと「⬇ ファイルに保存」のボタンを出し、初めて書き出した（PDF・PNG・印刷）あとに1回だけ「ファイルにも保存しておきますか？」と案内します（「今後表示しない」を選べます）。

そのほか：パートごとの色分け・編成表（人数）の自動集計・画像（PNG/SVG）・PDF保存・印刷・共有リンク・自動保存・元に戻す/やり直す。

## 使い方

1. `index.html` をブラウザで開く（または下の「公開する」の手順でWebに置く）
2. 左の「ひな形」から近い編成を選ぶ
3. 丸（奏者）をドラッグして動かす／何もないところをドラッグして範囲選択
4. 最後に「✨ きれいに整える」→ 上の「📤 書き出す」で画像・PDFに保存、または印刷（どの画面でもタイトル・サブタイトル・図面の情報欄を入れられます）

初めて開いたときは3つの手順だけの短い案内が出ます。くわしい使い方は右上の「？」ボタンで見られます。

## 公開する（GitHub Pages）

GitHub のリポジトリ画面で **Settings → Pages → Branch** に公開したいブランチとフォルダ `/ (root)` を選んで保存すると、
`https://<ユーザー名>.github.io/stagesetting/` で誰でも使えるようになります。

## ファイル構成

- `index.html` … 画面
- `css/style.css` … 見た目
- `js/catalog.js` … 部品（椅子・打楽器など）の種類と絵、パートの色
- `js/templates.js` … ひな形
- `js/halls.js` … ホールのステージ寸法（出典URL付き）
- `js/autolayout.js` … 人数から自動で並べる
- `js/figures.js` … 人の形の絵
- `js/view3d.js` … 3Dビュー
- `js/geometry.js` … 並べる・整える計算
- `js/trace.js` … 画像からの自動トレース
- `js/io.js` … 画像書き出し・保存・共有
- `js/checks.js` … 安全の確認（舞台奥の通路・上がり段・搬入経路・ホールの設備との重なり・出入り口の前）
- `js/app.js` … 画面の操作
