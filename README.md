# 🎼 ステージ配置図メーカー

吹奏楽・オーケストラ・ビッグバンドなどの**ステージ配置図**を、かんたんに作れるWebアプリです。
インストール不要。パソコン・スマホ・iPad のブラウザで動きます。

## できること

| こまったこと | このアプリでは |
|---|---|
| 細かい作業が面倒 | **ひな形**（吹奏楽・小編成・オケ通常/対向・弦楽・ビッグバンド）から一発で作成。<br>「8,10,12,14」と人数を入れるだけで**扇形の席をまとめて作成**。<br>「Fl×4, Ob×2, Cl1×3」で**パート名を一括割り当て**、名前も一覧を貼るだけで一括入力。 |
| きれいな形に整理したい | **✨きれいに整える**ボタンで、列を自動で見つけて**扇形（または横一列）・等間隔・指揮者の方を向く**ようにそろえます。パートの切れ目や通路のすき間は残します。<br>左右そろえ・等間隔・重なり解消・左右反転もあります。 |
| 既存のステージ図面を自動でトレースしたい | 配置図の**写真・スクショ・画像**を読み込むと、椅子（丸や四角）を自動で見つけて席にします。縮尺と指揮者の位置も自動で推定。オプションで文字（パート名）の読み取りもできます（ネット接続が必要）。 |

そのほか：パートごとの色分け・編成表（人数）の自動集計・画像（PNG/SVG）保存・印刷・共有リンク・自動保存・元に戻す/やり直す。

## 使い方

1. `index.html` をブラウザで開く（または下の「公開する」の手順でWebに置く）
2. 左の「ひな形」から近い編成を選ぶ
3. 丸（奏者）をドラッグして動かす／何もないところをドラッグして範囲選択
4. 最後に「✨ きれいに整える」→「🖼 画像」で保存、または「🖨 印刷」

## 公開する（GitHub Pages）

GitHub のリポジトリ画面で **Settings → Pages → Branch** に公開したいブランチとフォルダ `/ (root)` を選んで保存すると、
`https://<ユーザー名>.github.io/stagesetting/` で誰でも使えるようになります。

## ファイル構成

- `index.html` … 画面
- `css/style.css` … 見た目
- `js/catalog.js` … 部品（椅子・打楽器など）の種類と絵、パートの色
- `js/templates.js` … ひな形
- `js/geometry.js` … 並べる・整える計算
- `js/trace.js` … 画像からの自動トレース
- `js/io.js` … 画像書き出し・保存・共有
- `js/app.js` … 画面の操作
